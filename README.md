# CreditWise Loan Approval System

📌 Overview
- CreditWise is a Machine Learning project that predicts whether a loan application will be Approved or Rejected based on applicant financial and personal details. It helps reduce manual effort, bias, and improves decision speed.

💡 Problem
- Manual loan approval is slow, inconsistent, and prone to errors. This system automates the process using Machine Learning.

🧠 Solution
- A classification model is trained on historical loan data to predict loan approval outcomes.

⚙️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

🤖 Models Used
- Logistic Regression
- Decision Tree
- Random Forest

📌 Result
- Predicts loan status: Approved / Rejected
